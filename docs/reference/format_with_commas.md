# Format Number with Thousands Separator

Adds commas as thousands separators to large numbers

## Usage

``` r
format_with_commas(x)
```

## Arguments

- x:

  Numeric value or vector

## Value

Character vector with formatted numbers

## Examples

``` r
format_with_commas(1234567)
#> [1] "1,234,567"
# Returns: "1,234,567"
```
