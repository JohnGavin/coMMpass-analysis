# Get CoMMpass Data Dictionary

Returns a tibble documenting all known variables in the CoMMpass
dataset, including clinical, biospecimen, and RNA-seq data. Each
variable includes its category, data type, units, description, typical
range, and a link to the GDC data dictionary.

## Usage

``` r
get_commpass_data_dictionary()
```

## Value

A tibble with columns: variable, category, data_type, units,
description, typical_range, gdc_link

## Examples

``` r
dd <- get_commpass_data_dictionary()
# Filter to clinical variables
dplyr::filter(dd, category == "clinical")
```
