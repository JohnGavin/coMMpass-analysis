# Run Kaplan-Meier analysis

Run Kaplan-Meier analysis

## Usage

``` r
run_kaplan_meier(surv_data, group_by = "risk_group")
```

## Arguments

- surv_data:

  Survival data frame with time and status columns

- group_by:

  Column name to group by (default: "risk_group")

## Value

List with KM analysis results
